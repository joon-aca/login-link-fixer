# Changelog

## 1.2.1

- Fix Markdown links that escape the ampersands between query parameters.

## 1.2.0

- Left-clicking the menu-bar icon opens a valid clipboard link immediately in your default browser. Press `⌥⌘L` to confirm the destination first.

## 1.1.1

- Clarify the About window’s keyboard shortcut hint.

## 1.1.0

- Opening the app, pressing `⌥⌘L`, or clicking the menu-bar icon checks the clipboard. If the app can turn the copied text into a web link, it shows the destination and opens the fixed link in your default browser when you confirm.
- If the clipboard text can’t be turned into a web link, the fixer opens with the original text ready to edit. An empty clipboard opens a blank fixer.

## 1.0.0

- Initial macOS menu-bar release with a global shortcut, link repair for wrapped and Markdown links, and an optional Start at Login setting.
